## Featured Projects

### 1. MedLab Platform — Biomedical Laboratory Management Backend

**Repository:** [Davidn00/medlab-platform](https://github.com/Davidn00/medlab-platform)

A LIMS-inspired backend for biomedical laboratory workflows, built with Python and FastAPI.

**Highlights**
- Layered architecture separating API routes, business services, repositories, and persistence.
- REST API with versioning, validation, pagination, filtering, search, and dashboard statistics.
- PostgreSQL persistence with SQLAlchemy 2.0 and Alembic migrations.
- JWT authentication, role-based access control, password hashing, and audit logging.
- Asynchronous jobs and scheduled tasks using Celery with Redis/Valkey.
- Biomedical equipment, calibration, and maintenance workflows.
- PDF reports, data exports, automated tests, security checks, Docker, and GitHub Actions.
- Cloud deployment configuration using Render and Neon; public availability depends on the current deployment status.

**Stack:** Python, FastAPI, Pydantic, PostgreSQL, SQLAlchemy, Alembic, Redis/Valkey, Celery, JWT, Pytest, Docker, GitHub Actions.

### 2. InstrumentHub — Instrumentation Data Acquisition and Analysis

**Repository:** [Davidn00/instrument_hub](https://github.com/Davidn00/instrument_hub)

A modular platform for acquiring, processing, storing, and analyzing data from biomedical instruments and sensors.

**Highlights**
- Simulated data sources and foundations for physical instrument integration.
- Acquisition services, serial communication, and real-time measurement streaming.
- PostgreSQL/TimescaleDB persistence and REST APIs.
- Signal statistics, digital filtering, FFT, power spectral density, harmonic analysis, and anomaly detection.
- Optical interrogator integration and Fiber Bragg Grating (FBG) spectral analysis.
- React/TypeScript dashboard with real-time charts, experiments, alerts, and analysis views.
- Docker-based local environment, automated tests, and CI checks.

**Stack:** Python, FastAPI, asyncio, NumPy, SciPy, Pandas, PostgreSQL, TimescaleDB, SQLAlchemy, WebSockets, React, TypeScript, Plotly, Docker, Pytest, Ruff, MyPy.

**Deployment note:** AWS deployment is planned; do not interpret the project as already deployed on AWS.

### 3. Digital Thermometer — PIC18F4550 Embedded System

**Repository:** [Davidn00/digital_thermometer](https://github.com/Davidn00/digital_thermometer)

An embedded digital thermometer using a PIC18F4550 microcontroller, with temperature acquisition, filtering, display interfaces, alarms, and historical data logging.

**Highlights**
- LM35 temperature sensing and ADC acquisition.
- Interrupt-driven acquisition and digital filtering.
- LCD and multiplexed seven-segment display interfaces.
- I²C communication, EEPROM data logging, and alarm logic.
- Finite-state-machine-based control and Proteus simulation.

**Stack:** C, PIC18F4550, MPLAB XC8, ADC, interrupts, I²C, embedded systems, Proteus.
